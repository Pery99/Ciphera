Privacy Policy

Last updated: June 27, 2026

Ciphera is a portfolio messaging project. It is built to show privacy-first product and backend architecture, but it is not a production secure messenger.

What Ciphera Stores

Ciphera may store account details, usernames, hashed passwords, sessions, conversation membership, encrypted message payloads, attachment metadata, invite records, push subscriptions, and delivery/read metadata.

Message Content

Message payloads and media are designed to be encrypted by the client before storage. Ciphera should not be used for highly sensitive communication because it does not implement a production end-to-end encryption protocol.

Third-Party Services

Ciphera may use infrastructure providers such as hosting, PostgreSQL, Redis, Cloudinary, and browser push services. Those providers may process technical metadata needed to operate the app.

Contact

For questions, open an issue on the GitHub repository.
